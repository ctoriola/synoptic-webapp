To generate pitch decks from your GitHub repositories

Why do we need repository access?

Analyze your code

We read your README files, package.json, and other project files to understand your project structure and generate accurate pitch decks.

Your data is safe

We only read repository metadata and documentation. We never modify your code or store sensitive information.

Privacy first

Repository access is only used for pitch deck generation. We don't share your data with third parties.

Revoke anytime

You can revoke repository access at any time through your GitHub settings or account preferences.

What we access:

  • • Repository names and descriptions
  • • README files and documentation
  • • Package configuration files (package.json, requirements.txt, etc.)
  • • Repository metadata (language, stars, forks)

What we DON'T access:

  • • Your source code content
  • • Private keys or credentials
  • • Issues, pull requests, or comments
  • • Commit history or changes
